КАК ОТПРАВИТЬ ГОТОВЫЙ ПРОЕКТ НА GITHUB (Windows)

1. Распакуй весь ZIP в обычную папку. Не удаляй скрытую папку .git.
2. Открой https://github.com/new и создай пустой репозиторий practice5.
3. Выбери Public (если нужна открытая ссылка преподавателю).
4. НЕ ставь галочки Add a README, .gitignore или license.
5. Нажми Create repository.
6. В папке проекта дважды щёлкни PUBLISH_TO_GITHUB.bat.
7. Вставь HTTPS URL репозитория, например https://github.com/ТВОЙ_ЛОГИН/practice5.git, и нажми Enter.
8. Если GitHub попросит войти через браузер — войди и подтверди.
9. После SUCCESS открой страницу репозитория и проверь вкладку Commits.

Почему не использовать Upload files на сайте:
обычная загрузка файлов через браузер не переносит историю Git и коммит git revert.
BAT-скрипт отправляет обе готовые ветки вместе с историей.

Не отправляй никому пароль или токен GitHub. Авторизуйся только в официальном окне GitHub.
