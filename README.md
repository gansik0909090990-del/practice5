# Практикум 5 — автоматические тесты, исправление дефекта и Git Revert

## Описание

Учебный проект на Python с тремя автоматическими тестами `unittest`.
Функция `is_adult(age)` определяет, является ли человек совершеннолетним.

В первой версии проекта намеренно оставлен граничный дефект:
условие `age > 18` ошибочно считает человека в возрасте ровно 18 лет несовершеннолетним.
Тест `test_exactly_18` воспроизводит проблему. Исправление — заменить `>` на `>=`.

## Состав проекта

- `age.py` — тестируемая функция.
- `test_age.py` — три автоматических теста: основной, граничный и ошибочный случаи.
- `report.md` — отчёт с фактическими контрольными выводами тестов и Git.
- `evidence/` — текстовые логи контрольного запуска.
- `PUBLISH_TO_GITHUB.bat` — помощник для отправки готовых Git-веток на GitHub в Windows.

## Запуск тестов

В Windows PowerShell:
```powershell
py -m unittest -v
```

В macOS/Linux:
```bash
python3 -m unittest -v
```

Также обычно работает:
```bash
python -m unittest -v
```

После исправления все три теста должны завершиться с `OK`.

## Git-история

В репозитории уже создана история, показывающая:
1. коммит с тестами и исходным учебным дефектом;
2. отдельную ветку `fix/tested-bug`;
3. коммит минимального исправления;
4. отдельный учебный коммит;
5. его отмену командой `git revert` (история не переписана);
6. слияние исправленной ветки в `main`.

Посмотреть историю:
```powershell
git log --oneline --decorate --graph --all
```

Проверить состояние:
```powershell
git status
```

## Публикация на GitHub

1. На https://github.com/new создай пустой репозиторий с именем `practice5`.
2. Выбери `Public`, если преподавателю нужна открытая ссылка.
3. Не добавляй README, .gitignore или лицензию на сайте.
4. В распакованной папке проекта дважды щёлкни `PUBLISH_TO_GITHUB.bat`.
5. Вставь HTTPS-адрес созданного репозитория, например:
   `https://github.com/ТВОЙ_ЛОГИН/practice5.git`
6. Если откроется браузер авторизации GitHub, войди и подтверди доступ.
7. После успешной отправки открой страницу репозитория и проверь файлы и вкладку Commits.

Важно: загружай проект через `PUBLISH_TO_GITHUB.bat`, а не через веб-кнопку Upload files. Обычная загрузка файлов через сайт не переносит Git-историю и revert-коммит.
